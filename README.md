# SWYNEX Final Data Analytics Project – Healthcare Analytics

## 1. Problem Statement

The objective of this project is to analyze healthcare data to understand patient trends, hospital workload, admission patterns, medical conditions, and billing information. The analysis helps identify useful business insights that can support better healthcare resource planning and decision-making.

## 2. Dataset Information

The dataset contains healthcare-related patient records, including:

* Patient information
* Gender
* Medical conditions
* Hospital
* Date of Admission
* Discharge Date
* Admission Type
* Billing Amount
* Other patient-related details

## 3. Tools Used

* Microsoft Excel – Data preparation and cleaning
* SQL – Data analysis and querying
* Power BI – Data visualization and dashboard creation

## 4. Data Cleaning

The dataset was prepared before analysis by:

* Checking the dataset for missing values
* Correcting data formats
* Formatting date columns properly
* Checking duplicate or inconsistent records
* Preparing the data for SQL analysis and Power BI visualization

## 5. SQL Analysis

SQL was used to analyze the healthcare dataset and obtain important metrics such as:

* Total number of patients
* Hospital-wise patient counts
* Maximum, minimum and average billing amount
* Average patient stay duration
* Admission-type analysis
* Medical-condition analysis

## 6. Power BI Dashboard

A Power BI dashboard was created to visualize the healthcare data and provide an easy-to-understand overview of the analysis.

The dashboard includes:

* Patient overview
* Gender analysis
* Medical condition analysis
* Hospital analysis
* Admission trends
* Billing analysis

## 7. Key Business Insights

* Total patients analyzed: approximately 10K
* Female patients are slightly higher than male patients.
* Asthma has the highest patient count among the shown medical conditions.
* Smith PLC has the highest patient count among the top hospitals shown.
* Urgent admissions have the highest share.
* October has the highest number of admissions.
* February has the lowest number of admissions.
* Diabetes has the highest average billing among the shown conditions.
* Total billing amount is approximately ₹255.17M.

## 8. Business Value

The analysis provides useful information about patient demand, hospital workload, admission patterns, and billing differences. These insights can help healthcare organizations with resource planning, workload management, and monitoring of important trends.

## 9. Conclusion

This project demonstrates an end-to-end data analytics workflow using Excel, SQL, and Power BI. The project helped transform raw healthcare data into meaningful analysis and interactive visualizations, providing useful insights for healthcare decision-making.
